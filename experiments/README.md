# 实验目录

当前只登记实验计划，不包含已经完成的真机结果。

## 第一阶段必须补齐的实验

- 前台共享 WebView 与后台隐藏 WebView 的会话连续性；
- 执行权转移、用户接管、暂停、恢复和取消；
- DOM/结构化动作、视觉降级动作和页面后置条件验证；
- 轨迹去冗余、参数提取、Skill 回放和失败修订；
- ClosePaw/Aries/Ruto 后台表面的 API、ROM、输入和截图兼容性。

## 后续扩展实验

- Android API 28、32、33、34、35 的文件权限和 URI 撤销；
- `local-photo-search`、PocketSearch、ObjectBox、SQLite-vec 的端侧索引性能；
- 中文图片检索、OCR、跨模态召回和 Reranker 效果；
- 端云路由的延迟、上传字节、费用和隐私降级。

所有实验结果必须记录设备、ROM、Android API、应用版本、模型版本、数据集、步骤、原始日志和结论。
