# 源码证据索引

[`source-index.yaml`](source-index.yaml) 是参考项目源码核查的唯一索引，记录远程地址、项目角色、本地核查路径和具体文件。

## 使用规则

1. 先确认项目的 `evidence_level`，再引用结论；
2. `L1` 只表示已静态读取源码，不表示已经在目标 ROM 或设备上运行；
3. ROM、API、性能、功耗和中文召回结论必须另有实验记录；
4. 代码迁移前应固定 commit SHA，并重新检查依赖、权限、许可证、数据边界和资源释放；
5. README 的功能宣称不能替代源码证据。

## 当前缺口

- 尚无 `experiments/` 下的 ROM/API 真机结果；
- 尚无端侧模型、向量库和检索指标的统一基准；
- 本地研究目录尚未全部纳入 Git 子模块；
- 生产迁移前仍需生成固定 commit 清单和依赖许可证报告。
