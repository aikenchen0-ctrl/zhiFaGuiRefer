# 总体架构

## 分层

- 执行层：Virtual Display、Shizuku、无障碍服务、输入注入和截图。
- Agent Runtime：任务解析、观察、决策、工具调用、权限确认和人工接管。
- 记忆层：ActTree/轨迹索引、状态相似度、动作回放和经验检索。
- 技能层：参数、前置条件、动作步骤、成功判据、失效判据、回退策略和版本。

## 统一动作边界

Aries-AI 的输入注入、MobiAgent 的动作边、DroidAgent 的 UIAutomator2 脚本和 Ghost 的动作类，均先转换为统一动作表示，再交给 Android 执行器。

```text
屏幕截图 + UI 树 -> 状态快照
状态快照 + 动作 -> 统一轨迹事件
轨迹事件序列 -> 候选技能
候选技能 -> 回放验证 -> 技能入库或失效
```
